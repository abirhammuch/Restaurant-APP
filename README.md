# 🍽️ Restaurant App

A modern and responsive full-stack restaurant web application built with React and Node.js. Users can browse delicious meals, explore food categories, and enjoy a clean and interactive user interface.

## 🌐 Live Demo

https://restaurant-app-marshal-nine.vercel.app/

## 📂 Repository

https://github.com/abirhammuch/Restaurant-APP

## ✨ Features

### 👥 User Features
- User Registration & Login
- Browse Menu
- Search Foods
- Filter by Categories
- Shopping Cart
- Wishlist (Favorites)
- Food Ratings & Reviews
- Apply Promo Codes
- Secure Checkout
- Order Tracking
- Live Chat with Admin
- Google Maps Integration
- Dark & Light Mode
- Responsive Design

### 👨‍💼 Admin Features
- Admin Dashboard
- Manage Categories
- Manage Foods
- Manage Orders
- Manage Customers
- Manage Reviews
- Manage Promo Codes
- Live Chat with Customers
- Sales Analytics

### ⚙️ Technical Features
- JWT Authentication
- Protected Routes
- REST API
- Responsive UI
- Toast Notifications
- Image Upload
- Frontend & Backend Separation

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- JavaScript
- Vite

### Backend
- Node.js
- Express.js

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/abirhammuch/Restaurant-APP.git
```

### Navigate to the project

```bash
cd Restaurant-APP
```

### Install Frontend

```bash
cd frontend
npm install
npm run dev
```

### Install Backend

```bash
cd backend
npm install
npm start
```
